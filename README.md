# PatternSquare

Free, private tools that turn a photo into a printable craft pattern, starting with cross stitch. Everything runs in the browser; photos are never uploaded.

- `npm install`, then `npm run dev`
- `npm run build` builds the static site into `dist/`
- Pushing to `main` builds and deploys to Cloudflare Workers (`.github/workflows/deploy.yml`)

See `execution-plan.md` for the roadmap and `DESIGN.md` for the design system.
